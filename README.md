# «طيف» — الديمو التقني

ديمو لمحطة واحدة من ممشى «طيف»: لوحة مطبوعة، يظهر فوقها عمل فني بالواقع المعزز من متصفح الجوال، بدون تطبيق.

## محتويات المجلد

| الملف | وظيفته |
|---|---|
| `index.html` | صفحة البداية (يفتحها رمز QR) |
| `ar.html` | تجربة الواقع المعزز (MindAR + A-Frame) |
| `home.html` | النسخة المنزلية: العمل في بيت الزائر (model-viewer) |
| `config.js` | **الملف الوحيد اللي تعدّلينه**: اسم العمل، الفنان، المسارات، الحجم |
| `style.css` | التصميم |
| `assets/card.png` + `card.mind` | لوحة تجريبية من مكتبة MindAR، للتجربة قبل لوحتك |

الديمو يشتغل مباشرة بمجسم تجريبي مبني بالكود (حلقات ذهبية تدور). أول تجربة: افتحي `assets/card.png` على شاشة اللابتوب ووجهي الجوال عليها.

## الخطوة ١: جربيه على جوالك (٣٠ دقيقة)

الكاميرا ما تشتغل إلا على رابط **https**، فأسهل طريقة GitHub Pages:

1. سوي حساب GitHub، وأنشئي مستودع جديد عام باسم `tayf-demo`
2. ارفعي كل محتويات هذا المجلد (Add file → Upload files)
3. Settings → Pages → Source: `Deploy from a branch` → `main` / `root` → Save
4. بعد دقيقة يصير الرابط: `https://اسم-حسابك.github.io/tayf-demo/`
5. افتحيه في جوالك (Safari أو Chrome، **مو** متصفح إنستقرام أو واتساب)

## الخطوة ٢: لوحتك أنتِ

1. صممي صورة اللوحة: **تفاصيل كثيرة، تباين عالي، بدون مساحات فاضية كبيرة، وبدون تكرار** (الصور البسيطة جداً أو المتكررة ما يتعرف عليها)
2. حوّليها لملف `.mind` من [MindAR Compiler](https://hiukim.github.io/mind-ar-js-doc/tools/compile)
3. احفظيها في `assets/target.mind`، وغيّري في `config.js`:
   ```js
   targetSrc: "assets/target.mind",
   ```
4. اطبعيها على **ورق مطفي (غير لامع)**، مقاس A3 أو أكبر للشارع

## الخطوة ٣: العمل الفني (GLB)

1. جهزي المجسم في Unity أو Blender
   - من Unity: صدّري بـ glTFast أو UnityGLTF
   - من Blender: File → Export → glTF 2.0 → صيغة `.glb`
2. صغّري الحجم (الهدف: **أقل من ٨ ميجا**):
   ```bash
   npx @gltf-transform/cli optimize artwork.glb assets/artwork.glb --compress false --texture-compress webp --texture-size 1024
   ```
3. في `config.js`:
   ```js
   useModel: true,
   modelSrc: "assets/artwork.glb",
   modelScale: "0.6 0.6 0.6",   // كبري أو صغري حسب الحاجة
   ```
4. عدّلي `artwork` (العنوان، الفنان، النبذة)

> ملاحظة: الأنيميشن داخل ملف GLB يحتاج إضافة `aframe-extras`. للديمو، الأسهل مجسم ثابت أو أنيميشن بالكود مثل المجسم التجريبي.

## الخطوة ٤: الاختبار في الكورنيش

| الاختبار | النجاح يعني |
|---|---|
| آيفون (Safari) | الكاميرا تشتغل والعمل يظهر خلال ٣ ثوانٍ |
| أندرويد متوسط (Chrome) | نفس الشي بدون تقطيع واضح |
| ظهر وشمس مباشرة | يتعرف على اللوحة بدون انعكاس |
| بالليل | اللوحة واضحة (تحتاج إضاءة؟) |
| من مسافة ١ متر و٣ أمتار | يظهر من المسافتين |
| على شبكة 4G في الموقع | الصفحة تحمل في أقل من ١٠ ثوانٍ |
| فتح الرابط من QR | يفتح في المتصفح الصحيح |

## الخطوة ٥: فيديو العرض (٣٠–٦٠ ثانية)

1. **(٥ ث)** لقطة واسعة: الكورنيش واللوحة على العمود
2. **(٥ ث)** شخص يمسح رمز QR
3. **(١٥ ث)** من شاشة الجوال: العمل يظهر فوق اللوحة، والشخص يتحرك حوله
4. **(٥ ث)** بطاقة المعلومات وزر «خذ العمل لبيتك»
5. **(١٠ ث)** النسخة المنزلية: العمل في صالة بيت
6. **(٥ ث)** شعار «طيف» + «تقديم واحة اصطناعية، بالشراكة التقنية مع LVT» (بعد موافقتهم)

صوري شاشة الجوال بتسجيل الشاشة، والمشهد الواسع بجوال ثاني.

## القياس

كل الأحداث تُسجّل في `tayfTrack()` داخل `config.js`: فتح الصفحة، تشغيل الكاميرا، ظهور العمل، مدة المشاهدة. للديمو تظهر في Console. للنسخة الفعلية، ضعي رابط أداة قياس في `analyticsEndpoint`.

## إذا ما اشتغل

- **الكاميرا ما تفتح:** الرابط لازم https، ومتصفح عادي مو داخل تطبيق
- **ما يتعرف على اللوحة:** جربي صورة فيها تفاصيل أكثر، أو قرّبي الجوال
- **العمل يرتجف:** ثبتي اللوحة على سطح مسطح، وحسّني الإضاءة
- **العمل كبير أو صغير:** عدّلي `modelScale`
